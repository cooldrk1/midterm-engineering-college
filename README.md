# Engineering College — Multi-Page Website

Responsive static website built with HTML5, CSS3, Bootstrap 5, and vanilla JavaScript.

## Pages
- Home — index.html
- About & Programs — about.html
- Admissions — admissions.html
- Student Life — student-life.html
- Contact — contact.html
- Registration — registration.html

## Features
- Shared responsive fixed navigation and active page state
- Mobile-first layout, skip link, semantic landmarks, and visible keyboard focus
- Program and student-life category filters
- Accessible client-side validation and feedback for registration and contact forms
- Responsive custom CSS and reduced-motion support

## Limitations
Forms are demonstrations only: they do not send or store submissions. Do not enter real passwords or sensitive personal information. Institutional contacts, program details, events, and fees are illustrative and should be verified before official use.

Open index.html in a browser or use VS Code Live Server.

In repository Settings → Pages, select Deploy from a branch, choose main and /(root), then Save. After publishing, add the Live URL here.

## Project map
HTML pages are in the repository root; shared styles are in css/style.css and JavaScript is in js/script.js.
