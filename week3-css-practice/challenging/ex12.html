Sticky Header

Sticky header remains at the top while its panel scrolls.

Live result

Sticky demo header

Scroll inside this panel.

The header stays visible.

Useful for long pages and navigation.

HTML solution

<div class="sticky-frame"><header class="sticky-head">Sticky demo header</header><div class="sticky-content"><p>Scroll inside this panel.</p><p>The header stays visible.</p><p>Useful for long pages and navigation.</p></div></div>

CSS solution

.sticky-frame{max-height:230px;overflow:auto}.sticky-head{position:sticky;top:0;padding:1rem;background:#164e9a;color:white}.sticky-content{padding:1rem;min-height:420px}
